# Tarea 4 - Big Data (UNAD)
## Almacenamiento y Consultas de Datos en MongoDB

**Caso de uso:** Catálogo de productos para tienda virtual  
**Base de datos:** `tienda_db` → Colección `productos`  
**Autor:** Dagoberto Santisteban  

###  Cómo ejecutar
1. Instalar `mongosh`: https://www.mongodb.com/try/download/shell
2. Conectarse a Atlas o local
3. Ejecutar: `mongosh `

###  Operaciones implementadas
- Inserción masiva (100 documentos)
- CRUD completo
- Filtros con `$gte`, `$lte`, `$gt`, `$sort`
-  Agregaciones: `$group`, `$sum`, `$avg`
